# Tag 4 – GitHub Pages

Datum: 30.09.2026

## Was habe ich gelernt?

- Mit GitHub Pages wird aus meinem Repository kostenlos eine Webseite.
- Die Adresse ist immer `https://BENUTZERNAME.github.io/REPOSITORY/`.
- Die Datei `_config.yml` legt Titel und Design (Theme) der Seite fest.

## Welches Problem hatte ich?

- Direkt nach dem Aktivieren war die Seite noch nicht erreichbar.

## Wie habe ich es gelöst?

- Ich habe ein bis zwei Minuten gewartet. Im Tab **Actions** konnte ich sehen, wann die Seite fertig gebaut war.
