# Tag 6 – Verlauf mit git log, git show & git diff

Datum: 30.09.2026

## Was habe ich gelernt?

- `git log --oneline --graph` zeigt alle Commits als Baum, auch den Branch und den Merge.
- `git show` zeigt, was im letzten Commit genau geändert wurde.
- `git diff` zeigt Änderungen, die ich noch nicht mit `git add` vorgemerkt habe.

## Welches Problem hatte ich?

- Die Ausgabe von `git log` war so lang, dass ich nicht mehr zurück ins Terminal kam.

## Wie habe ich es gelöst?

- Mit der Taste `q` beendet man die Ansicht. Mit `--oneline` wird der Verlauf viel kürzer.
